# PlayBoard 系統總覽

歡迎使用 **PlayBoard** - 一個功能完整的教育互動平台。本文介紹系統的核心功能、架構設計和主要特性。

## 系統簡介

PlayBoard 是一個整合式學習管理平台，讓使用者可以透過測驗、文章、問卷和客製化頁面等，自行編排數位教材，並且可以自製教材的主題樣式。

## 核心功能模組

### 1. PlayBook（學習劇本）

**用途**：建立結構化的逐步學習體驗

**功能特性**：

- **步驟化學習**：將學習內容分解為多個有序步驟
- **多種步驟類型**：
  - 內容步驟 - 顯示文字和多媒體內容
  - 測驗步驟 - 整合線上測驗
  - 問卷步驟 - 收集滿意度反饋
  - 客製化頁面 - 載入互動式應用
- **進度追蹤**：自動記錄使用者完成進度
- **多主題支援**：內建 default、jungle、ocean 三種視覺主題

**適用場景**：課程教學、培訓計畫、產品導覽、知識學習路徑

### 2. 文章內容管理中心

**用途**：發布和管理知識內容

**功能特性**：

- 富文本編輯器 - 支援複雜的內容排版
- 標籤管理 - 分類和組織內容
- 內容預覽 - 發佈前檢視效果
- 草稿和發佈狀態 - 靈活的發佈流程

**適用場景**：知識庫、文章發佈、教材管理

### 3. 測驗管理系統

**用途**：建立和管理線上考試

**功能特性**：

- **多種題型**：
  - 單選題 - 標準選擇題
  - 複選題 - 多個正確答案
  - 判斷題 - 是/否選擇
- **自動評分** - 系統即時計算成績
- **詳細分析** - 統計答題情況和難度分析
- **成績記錄** - 完整的成績履歷

**適用場景**：教學評量、考試認證、知識檢測

### 4. 滿意度調查系統

**用途**：蒐集和分析使用者反饋

**功能特性**：

- **李克特量表**：5 階級滿意度評分（非常不同意 → 非常同意）
- **簡述題**：開放式文字回答
- **選擇題**：單選和複選選項
- **統計分析**：
  - 平均分數計算
  - 分布統計圖
  - 百分比分析
  - 文字回答整理
- **資料匯出** - JSON 和 CSV 格式

**適用場景**：課程評估、使用者體驗調查、滿意度收集

### 5. 客製化頁面

**用途**：整合自訂的互動應用和內容

**功能特性**：

- **ZIP 檔案上傳** - 支援完整的 HTML/CSS/JavaScript 應用
- **安全沙盒執行** - iframe 隔離環境保護安全
- **進度觸發機制**：
  - 手動觸發 - 使用者點擊下一步
  - 計時觸發 - 經過指定時間自動進行
  - 互動觸發 - 完成特定操作後進行
  - 完成觸發 - 達成條件自動進行
- **與 PlayBook 整合** - 作為學習步驟

**適用場景**：互動遊戲、專業應用、自訂學習工具
