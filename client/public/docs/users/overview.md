# 概覽

PlayBoard 是一個學習互動平台，可以建立課程、測驗、問卷等學習內容。

## 系統有什麼功能？

### PlayBook - 學習路徑

分步驟進行的課程。管理員可以建立多個步驟，每個步驟可以是：

- 閱讀內容
- 進行測驗
- 填寫問卷
- 互動遊戲或客製應用

學生依序完成每個步驟，系統會自動記錄進度和花費時間。

### 內容管理

發佈和管理文章、教材等知識內容。支援文字、圖片、多媒體等。

### 測驗

線上考試系統。支援單選題、複選題等題型，系統自動評分。

### 滿意度調查

收集意見回饋的問卷系統。支援：

- 滿意度評分（5 階級）
- 開放式文字問題
- 選擇題

系統自動統計分析結果。

### 客製化頁面

上傳自己編寫的互動應用（HTML/CSS/JavaScript），當作學習步驟使用。

## 誰能做什麼？

### 管理員

- 建立和編輯 PlayBook、內容、測驗、問卷
- 上傳客製化頁面
- 查看統計報告
- 管理使用者

### 一般使用者

- 參與 PlayBook 學習
- 閱讀公開內容
- 參加測驗
- 填寫問卷
- 查看個人學習進度

## 如何使用？

### 學習 PlayBook

1. 從管理員獲得連結
2. 進入後一步步完成內容
3. 完成後可看到統計和成績

### 參加測驗

1. 進入測驗頁面
2. 回答所有題目
3. 提交後立即看到成績

### 填寫問卷

1. 進入問卷頁面
2. 依次回答問題
3. 提交回答
