## 核心功能實作

### 1. 進度追蹤

- **自動記錄**：系統自動追蹤使用者在 PlayBook 中的進度
- **詳細資料**：記錄完成的步驟、未完成步驟、當前位置
- **時間統計**：追蹤每個步驟的開始/結束時間和總學習時間
- **進度同步**：各裝置間自動同步進度

### 2. 時間追蹤

- **步驟計時**：記錄每個步驟的花費時間
- **閱讀時間**：內容步驟自動計算實際閱讀時間
- **統計分析**：提供平均時間、最小/最大時間等統計
- **離線支援**：網路中斷時仍能記錄時間，恢復後自動同步

### 3. 統計分析

- **PlayBook 統計**：
  - 完成率分析
  - 步驟完成情況
  - 時間分布統計
  - 使用者進度對比
- **測驗統計**：
  - 答題情況分析
  - 難度分析
  - 成績分布
- **問卷統計**：
  - 滿意度平均分
  - 選項分布圖表
  - 文字回答整理
- **資料匯出**：支援 JSON 和 CSV 格式匯出

### 4. 多主題支援

系統內建三種視覺主題，可為不同 PlayBook 設定不同風格：

- **Default（預設主題）**：清爽現代風格
- **Jungle（森林主題）**：生機活力風格
- **Ocean（海洋主題）**：清涼舒適風格

### 5. 身份驗證與授權

- **登入系統**：安全的管理員登入
- **角色控制**：區分管理員和一般使用者
- **權限管理**：不同角色有不同的操作權限
- **會話管理**：自動登出和會話過期控制

### 6. 響應式設計

- **行動優先**：所有頁面都支援行動裝置
- **自適應佈局**：根據螢幕尺寸自動調整
- **觸控友善**：按鈕和控制項優化觸控操作

## 資料流向

### 典型的 PlayBook 學習流程

```
1. 使用者訪問 PlayBook 連結
   ↓
2. 前端載入 PlayBook 資訊和進度
   ↓
3. 顯示第一個未完成的步驟
   ↓
4. 使用者完成步驟內容
   ↓
5. 提交步驟完成
   ↓
6. 後端記錄進度和時間
   ↓
7. 前端載入下一個步驟
   ↓
8. 重複直到所有步驟完成
   ↓
9. 顯示完成頁面和統計資訊
```

### 典型的測驗流程

```
1. 使用者進入測驗
   ↓
2. 前端載入試卷和題目
   ↓
3. 開始計時
   ↓
4. 使用者回答所有題目
   ↓
5. 提交答案
   ↓
6. 後端自動批改
   ↓
7. 前端顯示成績和解析
   ↓
8. 記錄成績到使用者檔案
```

## 安全機制

- **認證**：所有管理功能需要登入
- **授權**：管理員功能只有管理員可以訪問
- **資料驗證**：前端和後端雙層資料驗證
- **安全沙盒**：客製化頁面在隔離環境中執行
- **HTTPS**：建議在生產環境使用安全連線

## 開發指引

### 命名規範

- **組件**：使用 PascalCase（例如：`UserList.vue`）
- **檔案**：使用 kebab-case（例如：`user-service.js`）
- **變數/函數**：使用 camelCase（例如：`getUserData`）
- **常數**：使用 UPPER_SNAKE_CASE（例如：`API_BASE_URL`）

### Git 工作流程

1. 從 `main` 分支建立功能分支
2. 完成開發後提交 commit
3. 建立 Pull Request
4. 經過 code review 後合併

### API 慣例

- 使用 RESTful API 設計
- 統一回應格式：`{ success: boolean, data: any, message: string }`
- 錯誤處理使用統一的錯誤中介層

### 樣式指引

- 優先使用 Tailwind CSS utility classes
- 避免在 template 中寫 inline styles
- 共用樣式提取到 `src/assets/` 目錄
