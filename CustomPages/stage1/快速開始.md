## 🚀 快速開始步驟

### 方法一：使用自動腳本（推薦）

1. **在檔案總管中開啟此資料夾**

   ```
   C:\wamp64\www\PlayBoard\PlayBoard\CustomPages\stage1\
   ```

2. **執行複製腳本**

   - 在此資料夾中找到 `copy-assets.ps1`
   - 右鍵點擊 → 選擇「使用 PowerShell 執行」
   - 如果遇到執行政策錯誤，請開啟 PowerShell（系統管理員）並執行：
     ```powershell
     Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
     ```
   - 然後再次執行 `copy-assets.ps1`

3. **檢查結果**

   - 腳本會顯示複製進度和結果
   - 確認所有檔案都成功複製（應該有 46 個檔案）

4. **打包上傳**
   - 將整個 `stage1` 資料夾內的所有內容壓縮成 ZIP
   - 確保 ZIP 內的根目錄包含 `index.html` 和 `config.json`
   - 在 PlayBoard 後台上傳此 ZIP 檔案

### 方法二：手動複製

如果無法執行 PowerShell 腳本，請參考 `README.md` 中的詳細步驟進行手動複製。

## 🎮 功能說明

### 遊戲規則

- **目標**：在 90 秒內正確分配出現的食物
- **操作**：拖放食物到正確的區域
  - 可分享食物 (shop1, shop2) → 左側分享區 (share)
  - 保存食物 (shop3, shop4, shop5) → 右側保存區 (box)
- **計分**：
  - 成功分配：增加分享分數
  - 逾時未處理：增加浪費分數

### 遊戲流程

1. 介紹頁面 → 點擊「開始」
2. 等待 10 秒查看遊戲說明
3. 進行 90 秒遊戲
4. 查看結果統計（分享 vs 浪費）
5. 觀看教育說明頁面
6. 觀看 YouTube 教育影片
7. 點擊「完成」→ 顯示 PlayBoard「下一步」按鈕

### PlayBoard 整合功能

- ✅ 自動追蹤遊戲時間
- ✅ 記錄分享和浪費分數
- ✅ 完成後發送進度資料給 PlayBoard
- ✅ 支援「下一步」按鈕整合

## 🔧 故障排除

### 問題：PowerShell 腳本無法執行

**解決方法：**

```powershell
# 以系統管理員身分開啟 PowerShell，執行：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 問題：圖片無法顯示

**檢查項目：**

1. 確認 assets 資料夾存在
2. 確認圖片檔案都已複製
3. 檢查檔案路徑大小寫是否正確

### 問題：音頻無法播放

**解決方法：**

1. 確認瀏覽器允許自動播放
2. 某些瀏覽器需要使用者互動後才能播放
3. 檢查音頻檔案格式是否正確

### 問題：ZIP 上傳後無法載入

**檢查項目：**

1. ZIP 根目錄必須包含 `index.html` 和 `config.json`
2. 不要將 `stage1` 資料夾本身放入 ZIP，應該壓縮資料夾內的內容
3. 檔案名稱不能包含特殊字符
